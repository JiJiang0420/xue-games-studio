引擎与编程01 / 14

Unity Manual

Unity 官方手册：场景、组件、物理、渲染与构建。注意选择与项目一致的编辑器版本。

准备使用 Unity 做 2D 或 3D 原型，具备基本 C# 语法。

阅读学习指南 ＋

建议学习顺序

  1. 编辑器界面、Scene 与 Game 视图。
  2. GameObject、Transform 与组件。
  3. Prefab 与场景管理。
  4. 输入、物理碰撞与 UI。
  5. 目标平台的构建流程。

动手练习

建立单场景收集原型：角色移动，触碰收集物后更新计数，完成后显示重开按钮。

完成标准

角色可以操作，收集物不会重复计数；重开后状态清零；目标平台构建可以启动。

注意事项

先记录编辑器版本。输入系统、渲染管线与包版本应与项目一致，不能直接混用不同版本教程。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

引擎与编程02 / 14

Godot Docs

Godot 中文官方文档，从第一个 2D 游戏到节点、信号与脚本。

希望从节点与脚本入门，制作轻量 2D 原型。

阅读学习指南 ＋

建议学习顺序

  1. 节点、场景与场景树。
  2. GDScript 基础与信号。
  3. 输入映射与角色移动。
  4. 碰撞层、遮罩与计时器。
  5. 项目导出与资源路径。

动手练习

实现躲避障碍小游戏：角色移动，定时生成障碍，碰撞后结束并允许重开。

完成标准

障碍会生成；结束后停止计分；重开不残留旧障碍；导出版本可运行。

注意事项

确认文档与项目的主版本一致；Godot 3 与 4 的节点、API 存在差异。导出可能需要安装对应模板。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

引擎与编程03 / 14

Unreal Engine Documentation

虚幻引擎官方文档，查阅蓝图、关卡与渲染工作流。

希望用蓝图制作 3D 交互原型。

阅读学习指南 ＋

建议学习顺序

  1. 编辑器、关卡与 Actor。
  2. 组件、蓝图变量与事件。
  3. 输入与角色控制。
  4. 碰撞、交互和 UI。
  5. 打包与目标平台配置。

动手练习

制作开门原型：进入交互范围后显示提示，按键打开门，离开范围后隐藏提示。

完成标准

范围内外提示正确；连续按键不会导致门状态异常；打包后交互仍可用。

注意事项

记录引擎版本、模板与目标平台；开始前核对官方硬件要求和磁盘空间。先做蓝图原型，再按需要引入 C++。

引擎与编程04 / 14

Microsoft C# 文档

学习 C# 语法、类型与异步编程，作为 Unity 脚本开发的语言参考。

需要读懂并编写 Unity 脚本，或独立学习 C#。

阅读学习指南 ＋

建议学习顺序

  1. 变量、类型与控制流。
  2. 方法、类、属性与访问控制。
  3. 集合、泛型与异常。
  4. 委托、事件与接口。
  5. 理解引用与值类型后再学习异步。

动手练习

实现纯逻辑背包：添加物品、合并数量、移除物品，并拒绝负数或库存不足的操作。

完成标准

覆盖添加、合并、删除最后一件和非法输入；操作失败时库存保持一致；记录实际输出。

注意事项

Unity 支持的 C# 与 .NET 特性取决于编辑器和运行环境。不要把 async 用作所有问题的默认方案；注意游戏对象 API 的线程限制。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

设计与架构05 / 14

Game Programming Patterns

在线阅读游戏编程模式，理解状态机、对象池、组件与事件队列。

已经写出一个小原型，开始遇到状态和模块耦合问题。

阅读学习指南 ＋

建议学习顺序

  1. 先阅读 Introduction 与 Architecture, Performance, and Games。
  2. State：表达角色或流程状态。
  3. Observer：拆分事件发送者和接收者。
  4. Object Pool：复用高频对象。
  5. Component 与 Event Queue：按实际需要继续。

动手练习

把原型中的待机、移动、受击改为显式状态；用事件更新 UI，避免 UI 直接管理角色状态。

完成标准

列出合法状态转换；重复受击、结束后输入等边界行为明确；改造前后玩法一致。

注意事项

先明确实际问题再引入模式。对象池需要重置状态，并不保证所有场景都更快；性能结论需要测量。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

设计与架构06 / 14

The Book of Shaders

从图形与交互示例学习片元着色器，适合探索程序化视觉效果。

对程序化视觉感兴趣，掌握基础代数与坐标概念。

阅读学习指南 ＋

建议学习顺序

  1. 片元着色器与归一化坐标。
  2. 颜色、插值与 shaping functions。
  3. 基本图形与距离。
  4. 平移、旋转与重复图案。
  5. 噪声与时间动画。

动手练习

制作可调颜色与频率的脉冲圆环，先在书中示例环境练习，再记录如何迁移到所选引擎。

完成标准

能解释坐标和颜色的关系；调整参数可以改变效果；不同画面比例下形状表现可解释。

注意事项

示例以 GLSL 为主，不是可直接复制的 Unity Shader。迁移到 HLSL、Shader Graph 或其他引擎时需要适配坐标、变量与管线。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

美术与素材07 / 14

Kenney

查找原型制作所需的 2D、3D 与界面素材；下载时检查具体资源包的许可。

需要快速搭建原型的占位场景、角色或 UI。

阅读学习指南 ＋

建议学习顺序

  1. 按 2D、3D 或 UI 筛选资源包。
  2. 阅读包内说明和许可。
  3. 检查尺寸、比例、格式和风格。
  4. 导入少量资源验证。
  5. 记录来源与改动。

动手练习

选一个资源包，仅用同一套素材搭建小场景，并制作可交互按钮。

完成标准

资源比例与碰撞范围合理；UI 可读；记录资源包名称、下载页、许可及实际使用文件。

注意事项

以具体资源包附带许可为准；不要根据站点名推断所有内容的授权，也不要把付费工具与素材包混为一谈。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

OpenGameArt

社区游戏美术与音频素材。不同作品许可不同，使用前核对署名和分发要求。

需要社区美术素材，并愿意逐项记录授权信息。

阅读学习指南 ＋

建议学习顺序

  1. 按风格、格式与用途筛选。
  2. 打开作品页阅读作者说明。
  3. 核对许可版本和署名要求。
  4. 保存来源与许可记录。
  5. 导入并验证兼容性。

动手练习

选择一个可用于目标用途的资源，制作小样，并写一段实际可用的署名文字。

完成标准

记录作品、作者、原链接、许可及修改；能说明是否满足商业使用和再分发条件；小样可运行。

注意事项

不同条目的许可不同，多个可选许可也需明确选用哪一个；不确定授权范围时先不用于发行版本。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

音频与音效10 / 14

Freesound

搜索环境声与音效。每条声音需要单独确认许可及商业使用条件。

为交互、环境和反馈寻找声音素材。

阅读学习指南 ＋

建议学习顺序

  1. 用具体声音事件而非泛称搜索。
  2. 试听并检查长度、噪声和动态。
  3. 核对每条声音的许可。
  4. 保存作者、来源与许可。
  5. 剪辑后导入原型。

动手练习

为同一按钮准备悬停、点击与确认反馈，控制音量并测试快速重复触发。

完成标准

声音与动作对应；无明显削波；重复触发不过度叠加；每条音效都有来源和许可记录。

注意事项

CC 许可种类不同，含 NC 的授权不适合未经额外许可的商业用途。下载可能需要账号；访问与授权状态以原站为准。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

音频与音效11 / 14

Audacity Support

学习录音、剪辑、降噪与导出，为游戏原型准备音频。

需要剪辑、整理或清理录音，用于游戏原型。

阅读学习指南 ＋

建议学习顺序

  1. 录音输入与电平。
  2. 选择、剪切、淡入和淡出。
  3. 按实际需要降噪。
  4. 检查峰值与静音。
  5. 导出并保留工程。

动手练习

将一段自有录音裁成短音效，去掉多余静音，加入短淡入淡出，导出供引擎测试。

完成标准

首尾无明显爆音；播放无削波；导出文件能被引擎读取；工程文件与原录音保留。

注意事项

使用官方下载渠道；不要反复有损转码。过强降噪会引入失真，格式、采样率与声道按项目需要选择。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

工具与发布12 / 14

Git 官方中文书

学习提交、分支与协作，让项目代码和开发记录可追踪。

希望为代码、文档与实验建立可恢复的版本记录。

阅读学习指南 ＋

建议学习顺序

  1. 起步：仓库与基本配置。
  2. Git 基础：status、diff、add、commit、log。
  3. 忽略文件与撤销操作。
  4. 分支与合并冲突。
  5. 远程仓库与协作。

动手练习

在单独练习目录提交两版文本，创建分支修改同一处内容，合并并手动解决一次冲突。

完成标准

能解释工作区、暂存区与提交；冲突标记已清除；日志能追溯改动；知道忽略文件不自动取消已跟踪内容。

注意事项

练习撤销先使用临时仓库；不要对现有项目盲目运行破坏性命令。不要提交密钥、缓存或大体积构建输出。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

工具与发布13 / 14

itch.io 开发者文档

了解游戏页面、上传构建和发行流程，适合准备原型试玩页。

准备给他人试玩原型，需要整理页面与构建文件。

阅读学习指南 ＋

建议学习顺序

  1. Creator 文档与项目页面。
  2. 平台与上传文件配置。
  3. 可下载构建与 HTML 游戏要求。
  4. 可见性、页面说明与截图。
  5. 更新流程和试玩反馈。

动手练习

先在本地准备发行包与页面文案，写明平台、操作、当前版本和已知问题；按需要在账号中建立非公开测试页。

完成标准

从干净目录解压可运行；依赖文件齐全；页面操作说明与实际一致；若进行非公开测试，检查访问权限。

注意事项

账号、上传与发布是独立操作，本指南没有执行。HTML 游戏有特定打包和运行限制；价格与分发条件以平台当前说明为准。

建议将实践步骤、使用版本与实际结果记录为学习笔记。以上练习均待实践。

Steamworks 文档

准备 Steam 商店页面与发行流程的官方参考，部分功能需要合作伙伴账号。

计划在 Steam 发行，准备了解后台流程与材料要求。

合作伙伴功能、费用、时间要求与政策以平台当前规则为准。此处仅整理学习与准备事项，不代表完成入驻、上传或发行。
