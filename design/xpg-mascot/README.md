## 原图与展示素材的约束

- 原图中的轮廓、心形、弯尾、道具和签名均作为固定资产保留。
- 归档原图和原样裁片保持不变；不使用此前造型偏离的重绘图集，不使用字体替代原手写签名。
- 当前网页使用单独的透明背景展示衍生图，背景清理过程与原样裁片分别记录。角色图始终等比缩放。
- 日常与彩蛋在同一个 440×300 比例画布内对齐角色和脚底；原签名由画布下方的单一节点显示，切换时保持位置与尺寸。
- 彩蛋展示角色、指针、心形撕纸洞口和星空手柄；外围说明文字、地面、网格、散落装饰不进入透明展示图。
- 原有游戏项目、学习入口和后台配置的联系方式继续保留。

三种主题中始终是同一个角色：温暖像素使用奶油色与珊瑚红纸感，暗色杂志使用深色背景与心形微光，工业科幻保留珊瑚红并增加青色轮廓光。

## 接入与检查约定

关于工作室区域展示与当前主题对应的日常角色及原签名，鼠标悬停或键盘激活可展示相应彩蛋；触屏应有明确的轻触切换方式，Escape 可关闭。支持减少动态效果偏好，保持清晰的键盘焦点与状态说明。

接入后逐主题核对默认和彩蛋截图，确保没有相邻面板的边框、拉伸、错位裁切或人物断裂；同时检查手机宽度的溢出、游戏项目、学习入口和联系功能。文件归档及裁片就绪与网站实际发布状态分别记录，不以原图收到代替部署成功。

## 当前网站接入：透明背景与统一尺寸

2026-10-29 清除背景残留后，按拥有者进一步放大角色、减少留白的要求，收紧共同透明画布并加宽角色一栏。

- 六张日常／彩蛋图片以对应原样裁片为参考，通过图像编辑工具生成透明背景衍生图。它们是经过背景清理的展示素材，**不是逐像素不变的原图，也不宣称恢复了原图中不存在的细节**。
- 再清除脱离主体的微小透明边缘杂点，等比缩放后放入统一的 **1320×900 RGBA** 画布。保留心形洞口、角色道具和主题轮廓光；不保留旧纸面、地板、网格和说明文字的矩形底色。
- 两状态原始画布均为 **1320×900**，共用源图矩形 **x=126、y=48、宽1134、高714** 作为可见窗口；该窗口包含六张素材的全部非透明像素，只隐藏外围透明留白。角色图与道具未重新生成、缩放写入或修改。
- 桌面左右栏为 **1 : 1.15**，角色窗口占满左栏；最大内容宽度时主体约 **222px** 高，比上一版约182px增大约 **22%**。手机窗口利用两侧内边距，最大428px，避免大块空白。日常与彩蛋始终共用尺寸、偏移和脚底基线。
- Logo 与角色区域间距缩至4px；脚底到签名的留白大幅缩短。完整星空洞口和光晕仍在窗口内，原签名节点保持固定。
- 三张签名仍使用原 **216×65** 裁片，只增加透明通道，RGB 字节保持不变；字体、笔画、颜色与原图一致。签名单独显示，切换状态时不移动，最大显示宽度216px。
- 移除原先的彩蛋多边形裁剪和角色背后的额外网格层。主题色、联系方式、游戏项目、学习入口不改动；关于区域仍与主体同宽。角色设定 PDF 继续作为独立交付文件，不加入网站。
