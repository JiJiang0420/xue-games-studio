# XPG 创造者化身

GLHF Studio 的个人创造者化身设计档案。设计方向确认于 2026-10-26。

## 设计方向

以工作室珊瑚红标志中的小写 `g` 为灵感，形成一个可以代替创作者本人出现在网站中的非人类角色。心形镂空、柔软轮廓与活泼姿态共同表达玩家和创造者的身份。

角色适用于网站插画、头像、作品署名及后续动画；GLHF 标志继续作为工作室的品牌标识。

## 固定造型

- 主体为珊瑚红、略不对称的圆润 `g` 形，底部有弯曲的逗号状尾部。
- 身体保留清晰的心形镂空。
- 配奶油色的短手套状手与短脚，以简洁动作表达情绪。
- 不添加人类五官、发型、服装或写实人体结构。
- 跨主题保持同一轮廓和主体配色，通过材质、心形内部光线和环境色适配页面。

## 状态与交互

| 状态 | 角色与场景 |
| --- | --- |
| 日常 | 角色坐着玩手柄，笔记本电脑置于旁边；姿态轻松、有趣。 |
| 鼠标悬停或键盘激活 | 角色一手托着笔记本电脑，另一只手拿着鼠标指针，在网页背景上打开心形撕纸洞口。洞内呈现梦幻星光和发光手柄。 |
| 鼠标移开或按 Escape | 恢复日常状态。 |
| 触屏 | 轻触切换，再次轻触恢复。 |

后续实现应支持键盘操作和减少动态效果偏好。心形洞口使用撕纸边缘；洞口和角色均应留在插画区域内，避免遮挡联系卡片。手柄采用前一版已选定的尺寸和线条粗细，结合后续确认的星光动效与渲染方向。
