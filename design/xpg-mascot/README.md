## 接入与检查约定

关于工作室区域展示与当前主题对应的日常角色及原签名，鼠标悬停或键盘激活可展示相应彩蛋；触屏应有明确的轻触切换方式，Escape 可关闭。支持减少动态效果偏好，保持清晰的键盘焦点与状态说明。

接入后逐主题核对默认和彩蛋截图，确保没有相邻面板的边框、拉伸、错位裁切或人物断裂；同时检查手机宽度的溢出、游戏项目、学习入口和联系功能。文件归档及裁片就绪与网站实际发布状态分别记录，不以原图收到代替部署成功。

2026-10-30 按拥有者确认的互动方案，将日常角色居中，停留后依次呈现心形回应、角色让位、指针与星空洞口展开。

- 现有六张 **1320×900 RGBA** 角色图和三张 **216×65** 签名图保持字节不变。它们仍是此前背景清理的展示衍生图；归档原图及原样裁片也保持不变。
- 角色和指针通过 SVG 遮罩分别显示既有彩蛋图片的相应区域，没有重新绘制角色。两种姿态使用同一缩放比例和脚底基线，靠平移及短暂淡入淡出完成交接。
- 三张独立洞口位于 `public/assets/xpg/layers/`。图像编辑工具从对应主题提取完整洞口并补齐原先被指针挡住的小段左侧边缘，随后清理零散透明噪点，等比缩入 **768×768** 画布。这些是新展示衍生图，不宣称与旧洞口逐像素一致。

- 鼠标停留先回应160ms，再展开560ms；移开有80ms容错并在360ms内收回。快速扫过不会延迟打开。触屏轻触开关，回车／空格开关，Escape关闭；失焦、切换主题或隐藏页面时复位。
