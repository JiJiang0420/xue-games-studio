叙事工坊 · GLHF 个人本地版 V1.4.1

一、Windows 首次打开
1. 将 ZIP 完整解压到一个固定文件夹，例如 D:\叙事工坊。不要在压缩包窗口里直接运行。
2. 如果电脑尚未安装 Node.js，到 https://nodejs.org/en/download 安装 Windows 版 Node.js 24 LTS 或更新的 LTS 版本。保持默认安装选项即可。无需安装 Git、Python、Ollama，也不需要执行 npm install。
3. 双击「启动叙事工坊.cmd」（英文备用入口为 Start_Personal_Writer.cmd）。
4. 启动器会打开 http://127.0.0.1:4178/ 。如果浏览器未自动打开，复制这个地址到同一台电脑的 Chrome 或 Edge。
5. 保持启动器窗口打开。用完后按 Ctrl+C 或关闭启动器窗口即可。

二、连接你自己的 ChatGPT Plus
1. 在工坊点「连接 ChatGPT Plus」，或打开「设置与备份」。
2. 点「使用 ChatGPT 继续」。在 OpenAI 官方页面登录自己的 Plus 账号，选择自己的工作区，并允许 Use your ChatGPT plan。
3. 授权页会返回本机工坊。设置里应显示「已授权使用 ChatGPT 套餐」和该账号的可用模型。
4. 点「用示例实测 OpenAI」。收到内置明信片故事的续写，才表示这台电脑与账号完成了实际生成验证。
5. 回首页输入想法，点「写成开头」；或贴入原稿，点「接着原文写」。生成结果先出现在候选框，审阅后点「接入正文」。

本入口只使用 ChatGPT 套餐：不会读取环境中的 API 密钥，也不能切换到 API 计费。无需填写 org、project 或 sk- 密钥。实际能否授权、可用模型和额度以 OpenAI 返回结果为准；套餐限制或资格不足会显示具体错误。

“本地版”指工作台和作品在你的电脑运行与保存。使用 ChatGPT 时仍需联网，相关原稿、人物设定和参考资料会发送给 OpenAI。它不是离线运行的大模型。

三、从在线版搬入旧作品
1. 在原来的在线工坊打开「设置与备份」，导出「完整备份 JSON」。
2. 在本地工坊同一页面点「导入备份 / 项目」，选择刚导出的 JSON。
3. 检查剧情集、角色、场景与章节是否完整。相同 ID 会另存副本，不覆盖现有作品。
4. 在线版和本地版不会自动同步。以后固定使用同一浏览器、同一浏览器用户和 http://127.0.0.1:4178/ ，并定期导出完整备份。

四、保存位置和个人使用
- 作品存于当前浏览器的 IndexedDB。不要用无痕窗口长期创作，也不要在未备份前清除此网站数据。
- Windows 套餐授权保存在当前用户的 %LOCALAPPDATA%\glhf-story-atelier\chatgpt.sqlite。不要把该文件发给别人或提交到 Git。
- 工作台只监听 127.0.0.1。此启动方式没有对其他电脑开放入口，也不会把你的作品发布到网站。
- 只转交导出的阅读页才会向接收者分享该页正文；「本地发布」只保存本机阅读快照。

五、常见情况
- 提示未安装 Node.js：安装后关闭旧启动器，重新双击。
- 提示 Node.js 太旧：安装 Node.js 24 LTS 或更新的 LTS 版本。最低技术要求为 22.13。
- 提示端口被占用：若工坊已经启动，继续使用原窗口。否则关闭占用 4178 的程序后重试。不要随意改端口，浏览器数据按网址分别保存。
- 授权取消：回到工坊，再点「使用 ChatGPT 继续」。
- 账号不具备套餐使用资格：在官方授权页核对账号和工作区；保留具体错误信息再排查，不能靠更换 API 密钥解决套餐授权问题。
- 达到用量上限：在设置中点「查看 ChatGPT 用量」，按账号显示的限制安排后续创作。
- 不要直接双击 Story_Atelier_Offline.html 来连接 Plus；该文件适合离线编辑，套餐授权需要本机启动器。

macOS：安装 Node.js 后运行 Start_Personal_Writer.command。
Linux：在解压目录运行 node start-personal.mjs。

本包已做自动化验证；真实账号登录和模型生成需要在你自己的电脑上完成。
