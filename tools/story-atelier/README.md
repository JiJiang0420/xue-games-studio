> 本目录用于源码维护，保存在 `xue-games-studio` 仓库的 `story-atelier` 分支、`tools/story-atelier/` 路径。
> 此次仅加入 Git 仓库，没有合并到 `main`，没有接入个人网站导航、构建或发布流程。

## 下载后先打开这里

- 离线工作台：[`offline/Story_Atelier_Offline.html`](offline/Story_Atelier_Offline.html)，下载该分支并解压后，用 Chrome / Edge 打开。
- 原创剧情示例：[`examples/story/Example_Project.json`](examples/story/Example_Project.json)，在工作台中导入。
- 独立阅读示例：[`examples/story/Example_Rain_Reader.html`](examples/story/Example_Rain_Reader.html)。
- 修改工作台后：在本目录运行 `node studio/build.mjs`，生成 `public/studio.html`；它也是可以独立打开的最新离线页面。`offline/` 保留 V1.0 交付快照。

仓库不包含 API 密钥、个人创作记录、运行缓存或部署凭据。全新下载的源码尚未配置 AI 密钥；文末的已部署环境验证记录不代表新环境已经完成配置。

一个中文剧情设计工作台：把想法整理成设定、大纲、正文与可交互的阅读版本。包含本地编辑器和服务端 AI 创作接口。

## 使用顺序

1. 点“开始新故事”，填写名称、创意、剧情类型、文学风格、标签、篇幅和章节数。
2. 需要时先在“角色与场景”建立人物动机、关系、成长弧线、场景感官与冲突，并在剧情集“设定”中绑定。
3. 在“创作知识库”查找内置方法卡、导入 TXT/MD 笔记，或点击“联网研究”按主题查找参考资料。联网研究显示可点击来源，保存后再绑定到作品。
4. 进入章节编辑，点“规划大纲”。检查大纲和分支后点“逐章生成 / 续写”。也可以完全手写，或导入 Markdown/JSON 正文。
5. 检查正文与事实记录，使用“检查连续性”获得修改建议。审阅不会自动改稿。
6. 打开“试读”，走通选项；在“本地发布”窗口保存独立快照，再从书架导出 HTML 阅读页。
7. 定期点右上角“备份”，保存完整 JSON。

## 数据、范围与边界

- 作品、设定、资料和发布版保存在当前浏览器 IndexedDB。不同设备、不同域名和离线文件的数据不会自动同步；用完整备份 JSON 迁移。
- 本地发布只在当前浏览器保存。在线工具本身的访问权限与作品发布是两回事。分享导出的阅读 HTML 才会把作品交给别人。
- AI 任务把当前设定、绑定人物场景、相关资料片段及必要上下文发送到 OpenAI。联网研究只发送研究框里的主题。服务端请求使用 `store:false`。
- 知识库是可扩充的摘要与检索系统，并未收录“全部人类知识”或所有书籍，也没有重新训练模型；资料事实需自行核对。只导入自有、获授权或适用的公版内容。
- 规模范围：500–300,000 个非空白字符、1–100 章；AI 每章目标 200–8,000 字符。单次输出有偏差，完成后显示实际总量。大任务需要保持页面打开；到预算上限可再次续写。
- 为防止互斥分支混淆，自动生成按照无环分支图排序，并仅使用所有入站路径共有的前驱事实。复杂状态变量、物品条件、数值判定、跨路线记忆尚未实现。
- 手动修改正文后，系统清除该章自动续写标记和旧事实摘要；请更新事实记录。自动写作跳过手工正文，避免无意覆盖。
- 每章生成最多 8 段后暂停，未达到目标会明确提示续写。长篇连续性仍需要作者审阅；单次审阅文本每章最多 7,000 字符。
- TXT/MD 单个导入限制 1 MB；全文读取以文本格式为主，不直接解析 PDF/EPUB。

## 离线编辑版

本目录内的 `offline/Story_Atelier_Offline.html` 是自包含页面，解压后用 Chrome/Edge 打开。它支持编辑、资料库、本地保存、阅读和导出，没有内置密钥，也不能独立调用服务端 AI。推荐用在线版使用 AI。

若浏览器禁用 file:// 下的存储，页面会显示保存异常；应先导出备份，并改用在线版或本地 HTTP 服务。

## 源码与开发

- `studio/`：前端源文件、知识卡、打包脚本。
- `public/studio.html`：自包含编辑工作台，由 `node studio/build.mjs` 生成。
- `app/api/agent/route.ts`：服务端模型网关，含身份和来源检查、结构化输出、联网研究及错误分类。
- `app/page.tsx`、`app/layout.tsx`：在线工作台容器。
- `tests/`：Node 测试。`node --test tests/*.test.mjs`。
- `studio/knowledge_sources.json`：18 条可核查来源与原创摘要。

在线版基于 Sites Vinext / Cloudflare Workers。开发环境要求 Node 22.13+，使用 package.json 指定的 pnpm。安装依赖后运行 `node studio/build.mjs`、`pnpm dev`；正式构建遵循 Sites 的构建与发布流程。不要把 `.env`、`.dev.vars` 或密钥提交到代码仓库。
